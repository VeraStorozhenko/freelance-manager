# Pre-Publish Checklist

## Product check

- Dashboard loads cleanly
- Notion MCP connects successfully
- MCP banner shows connected state after redirect
- Copilot answers after MCP connection
- Project Rescue Mode opens and shows a plan
- Follow-up note can be saved
- Hours can be logged
- Weekly review exports successfully

## Repo check

- GitHub repo is public
- `.env` is not committed
- `README.md` looks clean on the repo front page
- `LICENSE` is present
- `SUBMISSION.md` and `DEMO_SCRIPT.md` are present

## Submission check

- Video link is ready
- GitHub repo link is inserted
- dev.to post uses the official challenge template
- MCP usage is explicitly explained
- Project Rescue Mode is named as the signature feature

## Final narrative check

- One-line pitch is consistent everywhere
- The product is described as MCP-powered
- The product is not framed as a generic chatbot
- The main thesis is: Detect -> Explain -> Recover -> Write Back
