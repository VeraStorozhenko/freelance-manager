# Demo Script

## 60-second version

1. Open the dashboard and say: "This is a Notion MCP-powered operations system for freelancers."
2. Point to the MCP connection banner and confirm that the official Notion MCP server is connected.
3. Show urgent and at-risk projects in the dashboard.
4. Ask: `What needs attention today?`
5. Open **Project Rescue Mode**.
6. Show the rescue plan, internal recovery steps, and client-safe update.
7. Save a follow-up note or log hours from a project card.
8. Export the weekly review.

## 90-second version

1. Explain the problem: freelancers often already store work in Notion, but they still lack operational clarity.
2. Show the dashboard summary: urgent projects, at-risk projects, logged hours, tracked budget.
3. Mention that the app supports the official Notion MCP connection, so the copilot can work with live workspace tools.
4. Run a copilot prompt such as `What needs attention today?`
5. Open **Project Rescue Mode** for the riskiest project.
6. Explain the key moment:
   - the app detects risk
   - explains why the project is risky
   - proposes a recovery plan
   - drafts a client-safe update
7. Save a follow-up note or log hours to show write-back, not just read-only insight.
8. Export the weekly review and close by restating the product thesis.

## Talking points

- "Notion is not just storage here, it is operational memory."
- "The app uses the official Notion MCP server when connected."
- "Project Rescue Mode is the signature workflow, not just another AI summary."
- "The product is built around Detect -> Explain -> Recover -> Write Back."
